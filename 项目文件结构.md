**端口**：Nacos 8848（gRPC 9848/9849，控制台 8080）｜主管+前端 8091 ｜路线 8082 ｜行程 8085
**数据流**：用户输入 → 主管编排（TripOrchestrator 确定性 DAG）→ A2A 并行调两个子Agent → 校验/Reviewer 闭环 → 聚合JSON → 天卡片渲染；管线离线喂特征表供子Agent本地查询。

**分层约定（2026-10-11 重构）**
- `controller/` 只做 HTTP 适配（取 session、收参、调 service、返回），控制器内 `jdbcTemplate` 调用为 0；
- 业务全在 `service/`（响应体在这里拼）；SQL 全在 `repository/`（只放 SQL，不写业务规则）；共享设施在 `tool/`。
- HTTP 端点（方法级）100 处 = 主管 86 + 两个子Agent 观测端点 14，路径与重构前逐一相同。
